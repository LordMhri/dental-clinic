# Lewi Dental Clinic

Clinic management dashboard for Lewi Dental (Bole, Addis Ababa). React + Vite + TypeScript + Tailwind.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
